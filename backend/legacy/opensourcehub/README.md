# Retired OpenSourceHub source

These 51 files are retained as a reversible reference archive. They implement products absent from Code Arena and are excluded from src compilation and active tests. Original relative locations are preserved beneath this directory; restore them to the corresponding backend location only if intentionally reintroducing that product.

Ten retired tests exercised those removed modules, including some mixed historical hardening tests. Active Code Arena authentication, authorization, origin checks, battle judging and competition tests remain under backend/test. The reduced active test count reflects removal of retired product coverage, not suppression of failing Code Arena tests.

Shared migration history and tables have not been dropped. No environment files or secrets are included in this archive.
